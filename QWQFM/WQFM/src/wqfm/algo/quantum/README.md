# Quantum QAOA Module

This module contains the QAOA (Quantum Approximate Optimization Algorithm) implementation for quartet-based phylogenetic tree construction.

## Setup Instructions

### Option 1: Use Existing Virtual Environment

The project has a virtual environment at `/home/niloy/wQFM-2020/.venv`:

```bash
# Activate it
source /home/niloy/wQFM-2020/.venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Option 2: Create a New Virtual Environment

```bash
cd /home/niloy/wQFM-2020/WQFM/src/wqfm/algo/quantum

# Create virtual environment
python3 -m venv venv

# Activate it
source venv/bin/activate   # Linux/Mac
# or
venv\Scripts\activate      # Windows

# Install dependencies
pip install -r requirements.txt
```

### 3. Run the QAOA Script

```bash
# Using existing venv
/home/niloy/wQFM-2020/.venv/bin/python qaoa.py

# Or if venv is activated
python qaoa.py
```

## Use a D-Wave QPU for partitions larger than 20 taxa

Keep the API token outside the source code:

```bash
export DWAVE_API_TOKEN="your-token"
```

In `find_min_energy()` in `qaoa.py`, replace:

```python
best_x, best_energy = simulated_annealing(Q)
```

with:

```python
best_x, best_energy = dwave_quantum_annealing(Q)
```

The QPU function uses `EmbeddingComposite(DWaveSampler(...))` and returns the
same `(best_x, best_energy)` pair as the simulated-annealing function. Each
recursive subproblem with more than 20 taxa submits a QPU job.

## Dependencies

- **numpy**: Numerical computing library
- **matplotlib**: Plotting library for visualization
- **dwave-neal**: Local simulated annealing
- **dwave-system**: D-Wave QPU access and minor embedding

## File Structure

```
quantum/
├── README.md           # This file
├── requirements.txt    # Python dependencies
├── qaoa.py            # Main QAOA implementation
└── quartet.txt        # Input quartets (generated by wQFM)
```

## Input Format

The `quartet.txt` file contains quartets in the format:
```
((a,b),(c,d)); weight
```

Where `a,b,c,d` are taxa indices (1-based) and `weight` is the quartet weight.
